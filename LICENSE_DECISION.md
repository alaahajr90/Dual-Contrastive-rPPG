# Software Licensing Decision Required

This archive does not assign an open-source license without approval from the manuscript's authors and copyright holders. Before publicly publishing to GitHub, choose a license consistent with institutional agreements and contributions, and add the corresponding `LICENSE` text to the repository root. An absent license may prevent others from legally reusing the code.

Dataset acquisition permissions and use restrictions must be evaluated separately from the code license. Avoid placing facial-video data, physiological recordings, or third-party Dlib model files in the repository.
